# 第四战A「巨鹿之战」原作核对

数据直接取自用户提供的原游戏包，不按《三国演义》印象补写战场规则。地图来自 `HEXZMAP.R3` 第4节，战斗脚本来自 `SNR1D.R3` 第一章第13段，人物能力、头像编号、道具和兵种表来自 `BAKDATA.R3`、`MAIN.EXE` 及第一章解析结果。

## 已核对的战场数据

- 原版战场为18×18方格，30回合。
- 胜利条件为击退张郃，或者刘备抵达西面的鹿砦 `(0,10)`；刘备撤退或超过回合数失败。
- 地形共55平原、21森林、35草原、2村庄、52悬崖、157荒地、1鹿砦、1粮仓；本关没有河流和桥梁。两个村庄分别位于 `(11,7)`、`(7,13)`。
- 悬崖、城墙、城门、栅栏、房舍、火焰和浊流均按不可进入地形处理。森林和荒地按兵种计算移动消耗。
- 粮仓 `(5,8)` 获得麦；击退张郃胜利获得金200；刘备抵达鹿砦胜利时所有存活我军获得经验50。

## 部队与事件

- 我军：刘备；四个可出战槽位使用关羽、张飞、简雍等已加入人物。
- 友军：公孙越 `(10,4)`、羽则 `(9,5)`；第3回合关纯 `(17,13)`、耿武 `(17,12)` 加入。
- 敌军主力：张郃Lv10 `(5,17)`、颜良Lv7 `(6,15)`、高览Lv7 `(4,14)`、审配Lv6 `(12,6)`、逢纪Lv7 `(11,14)`，以及原脚本中的步兵、弓兵、骑兵、武术家和运输队。
- 第3回合，三个Lv3贼兵分别在 `(2,0)`、`(1,1)`、`(0,2)` 出现，同时触发关纯、耿武援军对白。
- 刘备进入中央区域 `x=4..10, y=8..13` 后，张郃等六支部队改为追击刘备。
- 张飞与颜良相邻交战时触发原作单挑；颜良败退，张飞获得原作事件升级。

## 重制实现约束

- 地图底图按原版18×18地形分区重绘；交互层仍使用真实方格，不能拉伸地图来伪造方格。
- 鹿砦、粮仓和两个村庄由运行时按原版坐标叠加；底图由四套同画风高清地形材质根据18×18数据自动合成，避免生成整图造成山崖与逻辑格漂移。
- 战前剧情沿用后续关卡规则：高清背景、人物头像和对白，不再放低清小人在场景中自由走动。
- 简雍Lv4弓兵没有固有策略；审配Lv6短兵和逢纪Lv7短兵按原版等级表具备焦热。敌军AI有物理攻击机会时优先攻击，并受策略冷却限制。
- 选关模式把前排平衡到Lv7、远程和辅助通常低一级；连续流程继续继承实际等级和装备。
