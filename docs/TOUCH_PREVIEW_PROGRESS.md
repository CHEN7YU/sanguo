# 手机和平板触控预览：开发与验收记录

2026-11-01，独立分支 `codex/touch-battle-preview`。正式站未发布本改动。

## 当前实现

- 独立 `battle-touch.js` 手势状态机：CSS 绘图坐标换算、单指拖动、双指中心缩放、边界限制、取消及多指抬起抑制误触。
- 实际 pointer 类型切换触控/鼠标布局；触控专用 CSS，不以窗口宽度单独启用。
- 常驻紧凑右栏、基本状态、两列指令；详情和物品菜单浮层；触控移动/攻击先预览，再次点目标或确认执行。
- 保存触控倍率、手动镜头暂缓自动跟随、视口变化保持中心；新增样式与脚本独立版本号。
- 本机预览：`PREVIEW_ASSETS` 指向完整发布包的 assets，运行 `node tools/serve_touch_preview.mjs`，端口 4176，仅监听本机，无账号 API。

## 已验证的证据与范围

- `node --check game.js` 通过。
- `node tools/verify_battle_view.mjs` 通过原有地图格坐标校验及新增触控测试。
- `tools/verify_battle_touch.mjs` 覆盖 CSS 比例换算、缩放锚点、大小地图边界、轻点/拖动、多指抬起、系统取消、倍率上下限。
- 本机 Edge 无头浏览器：568×320、844×390、1024×768 触控模拟及 1440×900 鼠标页面，无 pageerror。568×320 首轮发现结束回合按钮超界，随后压缩状态卡与留白；最终边界仍需重测。
- 淮南营寨测试位置，浏览器 touchscreen.tap：第一次触点只产生移动预览；点确认后单位坐标等于目标格。CDP 双指事件增大倍率，单位位置不变且无残留待确认移动。
