# 登录账号自动上传战绩（2026-11-02 北京时间）

用户要求登录玩家每关使用登录名自动提交战绩，并直接更新阿里云。

- `finish()` 结算后提交，登录玩家不再显示昵称输入和手动上传按钮；游客保留原流程。自动提交不打开排行榜，不中断剧情或下一关。
- 服务端读取真实登录会话，用户名和 `account:<userId>` 均由服务器决定；拒绝客户端账号不匹配、登录过期和游客伪造账号 ID。每账号每关保留最高成绩，同分保留更短时间。
- 待上传记录保存在浏览器，按账号隔离；恢复网络、刷新、页面重新可见和每分钟尝试补传。离线记录不会作为另一登录账号提交。浏览器禁用存储时仅能在当前页面内存中保留待上传记录。
- 小沛 `withdrawal` 胜利在服务端转换为已有 `alternate` 类型，不需要修改数据库结构。

验证：`tools/verify_auto_leaderboard.mjs`、`tools/verify_node_server.mjs`、`tools/verify_title_champions.mjs` 和 JavaScript 语法检查通过。包含匿名兼容、自动提交、断网/重载补传、账号隔离、场景切换、服务端身份防伪、重复上传和最高成绩保留。
