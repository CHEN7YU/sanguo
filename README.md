# 三国志昭烈传 · 经典重燃InktoLife出品

当前版本已经连通第一战“汜水关之战”、第二战“虎牢关之战”、第三战A/B“广川之战/信都之战”和第四战A“巨鹿之战”。这些关卡都按用户原游戏文件核对地图、参战人物、出生位置、关卡事件与基础数值，并使用同一套现代化操作、动画、音效、存档和触控界面。

点击“开始游戏”后会先播放用户提供的高清开篇动画；网页版本已裁去前约5秒广告并压缩为H.264/AAC 480p，点击、轻触或按任意键均可跳过。动画结束后进入原作序章：从董卓擅权、诸侯陈留会盟，到华雄来袭、刘备请战、袁术反对、曹操准许并拨付金500，再由公孙瓒与陶谦随军。剧情支持任意键逐句推进、自动播放及整段跳过，之后进入军需整备与第一关战场。

## 后续剧情制作规则

- 后续关卡的剧情表现统一采用“每个场景一张高清重绘背景＋人物立绘＋对话框”的形式，按原作场景、人物、对白和事件顺序推进。
- 不再制作刘备在剧情场景中自由走动的小人，也不以场景小人走路作为剧情交互；已有自由走动方案不作为后续关卡模板。
- 原作允许选择人物交谈时，直接在当前背景图上显示清晰的人物选项；选择后进入该人物的立绘对话，结束后返回选项界面。
- 道具屋同样使用专用背景图和菜单选项，购买、出售、转交、整备和离开均在该界面完成，不制作人物在店内走动的流程。
- 背景、立绘、按钮和文字继续适配电脑、手机及平板横屏；选项必须支持鼠标、键盘和触屏。
- 这一规则只简化剧情操作表现，不删减原作对白、分支、奖励、整备、存档节点和剧情状态继承。

## 阵营形象规则

- 我方与友军的具名人物优先使用专属战场形象；暂时没有专属素材时，可以复用相符兵种的动作结构，但必须自动切换为蓝、青、白等友军色系，不能直接显示敌军红色素材。
- 该阵营配色必须同时覆盖待机、移动、攻击、受伤、濒死以及队伍头像。以后新增我方或友军人物默认继承这条规则，待专属形象完成后再取消通用配色。

开始画面循环播放用户提供的《三国志11》主题音乐，开始新游戏时淡出并交给开篇动画。开始游戏、继续游戏和标题页读档都会请求浏览器全屏；支持网页全屏的电脑和安卓设备会直接进入全屏，iPhone/iPad 受 Safari 系统能力限制时保持最大化横屏布局。

## 启动

双击 `启动试玩.bat`，或在本目录运行：

```powershell
node server.mjs
```

浏览器打开 <http://127.0.0.1:4173>。

原版第一关数据对账：

```powershell
node tools\verify_level01.mjs
node tools\verify_battle_rules.cjs
```

第一项会把试玩版的28×16地形、12个参战单位、战役元数据、装备和开场事件与从原游戏文件提取的JSON逐项比较；第二项校验士气、撤退、混乱恢复与命中率边界。

原版第二关数据对账：

```powershell
node tools\verify_level02.mjs
```

广川、信都与巨鹿数据对账：

```powershell
node tools\verify_level03_guangchuan.mjs
node tools\verify_level03_xindu.mjs
node tools\verify_level04_julu.mjs
```

巨鹿关使用从原游戏解出的18×18方格地形、原版部署与30回合限制。第3回合触发三支贼兵伏击以及关纯、耿武来援；刘备进入中部会让张郃军转为追击；张飞邻接颜良触发单挑。击退张郃获得金200，刘备抵达西面鹿砦则让全部存活我军获得经验50，不重复领取普通胜利金。

第二关直接访问 <http://127.0.0.1:4173/?level=2>。页面先进入虎牢关战前道具整备，再播放行军与开战对白。正常通关汜水关后，结算按钮会进入虎牢关；刘备、关羽、张飞、公孙瓒、陶谦的等级、经验、剩余兵力、士气、策略值、道具、宝物和军资金自动继承。虎牢关包含原版16×24地图、12个单位、30回合限制、第18回合吕布出击、宝物库焦热书、兵粮库豆、张飞与吕布单挑以及普通击退吕布两种胜利流程。张辽采用专用骑马待机、四向行进、马上挥刀和落马退场表现，同时保留原版短兵数值、移动规则与守位AI。虎牢关另有专属河道流纹与树林摆动遮罩，动态只作用在对应地貌，并避开桥面。选中张飞会显示单挑触发提示；通关后在洛阳关卡尚未制作期间返回开始画面。

地形信息会按当前查看或行动单位的实际移动类别显示消耗；例如轻骑兵指向森林会明确显示“不可进入”。鼠标悬停、触屏点格和键盘光标使用同一套提示，移动路径继续显示逐格累计消耗。宝物库与兵粮库的提示直接读取当前关卡事件，因此虎牢关宝物库会显示并实际给予焦热书×1，而不会误用汜水关的金100奖励。

战场左上角同时显示胜利条件和当前关卡的败北条件，战况记录也会在开战时写入两项规则。虎牢关会明确提示“刘备撤退或超过30回合”判负。

主菜单提供“选择关卡”，并从所选关卡的剧情起点进入。选关属于独立试玩：系统根据该关敌军平均等级与主将等级自动给我军补到均衡推荐等级，只提升等级不足者，远程与辅助通常比前排低1级；当前推荐为汜水关前排Lv.3、虎牢关Lv.4、广川关Lv.4、信都关Lv.5、巨鹿关Lv.7。连续通关和读取存档仍继承玩家的实际等级、经验与军需，不套用选关补正。“继续游戏”和“读取进度”会识别存档所属关卡，并自动跳转后恢复对应进度。旧版未记录关卡ID的存档会按关卡名称兼容识别。

界面以 1920×1080 为最低设计基准，支持 2560×1440 和 4K 自适应；低于 1080p 时也可缩放预览。

## 操作

- 左键选择我军，点击蓝色格移动，点击红色范围内敌军攻击。
- 敌军已经相邻时，可点击右侧“攻击”原地出手；鼠标移到目标上会显示伤害与士气损失区间、溃退风险、命中、会心、格挡、反击概率、预计反击伤害、兵种克制和地形防御。
- 悬停可移动格会显示实际寻路路线以及逐格累计消耗。“敌军危险区”显示敌军移动后的物理攻击范围，并纳入当前站位可施展的火攻与牵制范围。
- 每名主要武将使用独立五帧攻击动作：刘备双剑连斩、关羽关刀挥砍、张飞与公孙瓒长矛直刺、陶谦与华雄刀剑攻击；普通刀兵、矛兵和弓兵也有对应动作。所有阵营和兵种在受到致命攻击时都会倒地、扬尘并淡出，旌旗同步消失；关羽、张飞、公孙瓒和华雄另有各自五帧马匹失衡、跪倒、人与马落地动作，不再把整张骑兵图直接旋转压扁。
- 第一关全部12个单位都已接入四方向、每方向四帧的专门行走图。刘备、关羽、张飞、公孙瓒、陶谦和华雄使用各自重绘素材，其他武官、弓兵与普通步兵使用对应兵种素材；行进时按真实路径换向，并逐帧校准脚底和人物尺寸，不再用整张人物图旋转、漂移或压缩来冒充走路。
- 近战攻击会根据目标所在格自动判断东、西、南、北方向：东西方向使用武器专属五帧动作，南北方向使用对应朝向的逐帧姿态配合突进和武器轨迹，不会在纵向交战时突然转成侧脸。演出包含蓄力、突进、武器命中、停顿、震屏和伤害数字；受击单位连续经历闪白、压缩扭身、击退和回弹，弓兵保留清晰的侧向拉弦动作，箭矢会按实际目标方向飞行。
- 策略菜单按原版兵种与等级学习表显示：短兵6级才学会焦热，轻骑兵8级才学会牵制，援助只属于具备恢复策略的辅助兵种。第一关全部参战单位等级不足，因此没有固有策略；火攻必须使用焦热书，恢复必须使用豆，骑兵不会凭空出现援助指令。
- 自动阵营同样受策略学习表约束，并且本回合能移动后物理攻击时始终优先交战；策略另有回合冷却和重伤恢复门槛，避免敌军连续施法而很少使用兵器攻击。
- 开战前可在道具屋购买豆、酒和焦热书，并指定刘备、关羽或张飞携带；消耗品、青龙偃月刀和蛇矛都能逐件转交给另一名我军武将。每名武将的宝物和道具合计最多8件，攻击加成随宝物持有人实时重算；“恢复初始军需与宝物”会恢复进入当前关卡时的军资金、道具和宝物归属，不会抹掉上一关的继承状态。公孙瓒、陶谦按剧情固定加入，无需在道具屋重复邀请。战斗中“道具”指令按携带者独立计数，可用豆恢复200兵力、麦恢复400兵力、酒恢复50士气；焦热书按原版规则必中，伤害由基础威力200减去目标策略能力后随机浮动，树林再增加25%，并给予攻击经验。村庄和鹿砦在对应阵营回合开始时恢复兵力与士气。状态栏实时显示士气，低于30时用红色提示混乱风险。宝物栏会显示青龙偃月刀攻击+12%、蛇矛攻击+10%等已计入数值的原版效果。
- 武将攻击和击破敌军会获得经验，击破强敌与主将奖励更多；经验达到100后升级并保留溢出经验，同时提升兵力上限、攻击和防御。右侧武将信息与出阵列表会实时显示等级和经验。
- 战场单位头顶在兵力条下方显示士气条，出阵列表也显示每人的士气数值；低于30时统一转为红色警示。
- 右键取消行动；也可使用右侧的待机、取消和结束回合。方向键移动键盘光标，Enter确认，A攻击、S策略、W待机、D危险区、Esc取消、空格结束回合。
- 鼠标滚轮缩放地图，按住中键拖动画面；触控板支持双指平移与捏合缩放。
- 设置里可开启“重复战斗动画自动加速”：同类攻击第一次完整播放，后续自动提速，关键会心、格挡与死亡表现仍会保留。
- 右上角设置可以调整0.75×—2×动画速度、独立音效音量、界面比例以及全屏；BGM音量保持独立控制。

当前战场采用贴近原作的高清手绘地图和单人将领棋子，战术层是从用户原版 `HEXZMAP.R3` 直接解码的28×16、448格地图。河流是连续硬阻挡，所有部队只能通过原版坐标 `(17,10)` 的唯一木桥；村庄、鹿砦、兵粮库、宝物库及全部12个单位均按原版坐标放置。公孙瓒、陶谦作为盟军在独立阶段自动行动。第一关还包含30回合限制、命中与闪避、会心与格挡、兵种克制、地形效果、宝物与兵粮、经验升级、关羽斩华雄事件、胜败剧情和结算。原版半伤反击规则已实现，但首关参战兵种都不满足触发条件。

战场环境包含持续动态效果：河面高光与涟漪沿水流移动，树林树冠随风轻摆并伴有少量飘叶。环境动画独立限帧运行，战斗动画期间会自动让出绘制节奏。

地图单位身后的旌旗使用独立动态旗面，会随风连续起伏，并在单位移动、攻击和受击时跟随所在位置；武将旗和普通军旗采用不同尺寸。

剧情对白会随说话者切换专属立绘；曹操、袁绍和袁术的新立绘分别严格取自原版人物记录所指向的 FACEDAT 头像 27、110、144，再据此高清重绘，军报等非人物对白使用阵营徽记。具名武将在兵力归零时会留下战败遗言，再继续回合或进入胜负结算；华雄沿用原版剧本台词，其余武将按人物身份补写。

对话框支持点击、轻触或任意键推进，并可整段跳过剧情。关羽与华雄触发单挑后会切入专用宽银幕场景，连续表现冲锋、三合攻防、武器碰撞、招架、最后一刀和华雄倒地；随后播放“酒尚温，将已还”的温酒镜头，并压低战场音乐突出收刀与热酒余韵。
